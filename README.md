# Saltwind

Saltwind is a third-person tropical island exploration project for Unreal Engine 5.8.

## Open the project

Install Unreal Engine 5.8, Git LFS, and the Windows C++ build tools required by Unreal. After cloning, run `git lfs pull` and open `Saltwind.uproject`. Let Unreal build the game module when prompted. The startup map is Coral Reach.

## Explore

WASD moves the character and the mouse controls the camera. Space jumps on land or surfaces in water. Hold C to dive. N advances the day–night cycle, R returns to the beach, and F1 toggles the controls.

Package for Windows from the Unreal Editor. Asset credits are in [ASSET-CREDITS.txt](ASSET-CREDITS.txt).
